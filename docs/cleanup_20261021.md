## Preserved workflows and historical evidence

The 35 retained scripts cover v2 preparation, replay, calibration, reference diagnostics,
ACT/flow training and evaluation, trace collection, conditional simulated demonstrations,
and legacy commands exercised by tests. The remaining source package retains legacy
single-camera checkpoint loading, simulation, training and recovery-policy interfaces.
Superseded standalone experiment drivers are recoverable, not supported active commands;
restore a historical driver and its inputs before following an old dated experiment recipe.

All completed-run best/last checkpoint bundles, their optimizer states where present,
and explicitly referenced baseline checkpoints remain in place. Fresh screen artifacts
are not trimmed by this cleanup. Only obsolete intermediate and short smoke checkpoints
are discarded. Their exact weight files are **not archived**; reproducing them requires
retraining, which is not promised to be bit-identical. The unused cloud upload bundle can
be regenerated from retained local data. No job was running during the cleanup check.

The latest v2 controller traces and source snapshots, R3 hold evidence, reviewed condition
panels, calibration inputs, historical aggregate trial CSVs and contact-retention summary
remain directly available. Older untracked metadata/media are packed into one verified
local archive, `outputs/archive/cleanup_20261021_metadata.tar.gz` (91,622,434 bytes).
The removed loose files total 13,689,022,822 bytes, giving about **13.60 GB net logical bytes**
removed after this archive, before small new docs. This is not a claim about APFS physical
free space, sparse files, Git history, or snapshot reclamation.

## Exact recovery

[The manifest](cleanup_manifest_20261021.json) records each removed path, size, SHA-256,
recovery source and base commit `ab5a4a37f2da64bfc8bf634fd53e93709c7feb1a`.
Tracked files recover from local Git blobs; untracked metadata recover from the local archive.
The archive is ignored by Git and is not a remote backup. Copy it separately if migrating
machines. The earlier cleanup still uses `cleanup_manifest_20261020.json`.

List or restore one historical script without resetting current work:

```sh
.venv/bin/python scripts/restore_archived_results.py \
  --manifest docs/cleanup_manifest_20261021.json --path scripts/diag_recorded_grasp_control.py
# Add --out-dir . to restore a missing file at its original path.
```

Recover old diagnostic metadata or media using the same command with its original path.
The tool verifies SHA-256, refuses overwrites/path escapes, and refuses restoration of
checkpoint weights explicitly marked as not archived. It never extracts arbitrary tar paths.
Historical documents may refer to removed artifact paths: use the manifest to restore those
inputs first, rather than treating a missing preview as missing experimental evidence.
