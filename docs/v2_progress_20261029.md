# Project progress — 29 October 2026

The working simulation pipeline remains frozen HF ACT followed by RGB geometric
recovery. A separate learned recovery MLP now completes some tasks on both arms,
but its current 30% development success does not meet the 60% target. Lighting,
the physical measurement inputs and the native HF weights remain unchanged.

For the learned head, the first two seeds were used to compare candidates;
eight additional fixed seeds then scored 2/8 on each arm. The total 3/10 is a
descriptive development result, not an independent reserved benchmark. All 20
phase-head attempts retain the same head and base weights, use no geometric
teacher actions, and finish without aborts. The unsuccessful trials stay in the
denominator. The user's reported 4/5 real-checkpoint result is separate hardware
evidence; these simulation results do not evaluate the real checkpoint on the
physical arm.

## Completed work

- Audited all 600 matched benchmark trials, reset fingerprints, trace hashes and
  declared runtime inputs. RGB alone reaches the same success ceiling as the
  assisted system; ACT participation does not establish a causal improvement.
- Implemented common Cartesian recovery actions with native FK/IK, workspace,
  collision and path checks for both arms. Added magnitude backtracking, bounded
  numerical seeds, command-stop margins and Panda's declared top-down orientation.
- Collected actual learner-visited corrective states with DAgger and trained
  separate residual, no-ACT and phase-supervised heads. The MLP executes actions;
  DAgger supplies the iterative collection/training procedure.
- Added fresh RGB reference memory, explicit observation ages, cumulative goal
  drift detection, command-aligned phase labels and missed-pickup replanning.
  The latest missed-pickup correction postdates the current training packs, so
  it requires new collection before a learned head can benefit from those labels.
- Preserved source snapshots, exact model inputs and checkpoint/head hashes for
  new runs. Fixed factory artifact hashing, cleanup and direct/module invocation.
- Ran a separate fixed-lighting RGB robustness pilot: 42/42 across both arms and
  seven layout/radius/friction conditions, with three seeds per condition. The
  perception frontend knows the varied radius; this is a small scene-aware pilot.

## Remaining bottlenecks and next work

1. **Grasp verification and retention.** Predicting LIFT does not prove that the
   ball is held. Some failures never grasp; several Panda failures genuinely
   lift, then lose the ball about 6–7 cm above the table while still commanding
   closed jaws. SO101 can regress to an open pre-grasp command during transport.
   The next experiment should separate grasp centering/contact from motion
   smoothness, add observable grasp-loss feedback, and collect new corrective
   trajectories using the fixed teacher. The successful geometric baseline uses
   the same physics, so changing physics to inflate a head's score is unwarranted.
2. **Recovery-state coverage and memory.** Successful demonstrations do not cover
   prolonged failures, stale references or repeated jaw changes. Added DAgger
   examples help, but timing/reference-age inputs still extrapolate. The RGB
   frontend estimates on-table ball position and remembers it during occlusion;
   it does not measure the carried ball in 3D.
3. **Panda-to-SO101 state coverage.** Both generic ACT-residual Panda trials in
   tracked iteration 1 abort when a native-feasible Panda pose cannot be mapped
   into virtual SO101 state within the declared 3 mm tolerance. This needs an
   explicit representation/uncertainty strategy and training coverage; relaxing
   the tolerance alone would not validate the resulting ACT inputs.
4. **Simulation camera alignment.** At identical recorded joint states, replacing
   the global image with its render increases action error more than replacing
   the wrist image. The measured dimensions are present and used. Remaining
   optical/frame registration needs independently identifiable calibration; the
   good real ACT checkpoint should stay frozen while this mismatch is resolved.
5. **Intervention-gate supervision.** The first gate dataset contains only
   correction-positive examples, so its saved conservative gate always recovers.
   It cannot learn when ACT is sufficient without genuine negative examples.
